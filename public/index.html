Models & providers

    
Default model

    
New chats start with this model (“Last used” keeps the model you picked last).

    
    
Where your prompts go

    
Models marked ☁ run outside this computer: Ollama cloud models and providers on another host. Lumen asks once per destination before the first prompt goes there.

    

    
OpenAI-compatible providers

    
Any server with the /chat/completions API: MiniMax, OpenRouter, LM Studio, a llama.cpp server… The key goes into the secret store and is never shown again.

    

    

      

      
      
      
      
      

      

    

    
Secret store

    

    

    

  



  

    
☁ This model runs outside your computer

    

    
Your messages, the chat so far, attachments, project knowledge and memories in the prompt are sent there. You can revoke this in Settings › Models & providers.

    

  



  

    
Workspace

    
This is not a sandbox. The model can read the files of a trusted folder. Every edit (unless a chat is in auto-edit mode) and every command needs your approval, and an approved command runs with your own permissions.

    
Trusted folders

    
Type an absolute path (browsers cannot pick folders). Your home folder itself, system folders, ~/Library, ~/.ssh, ~/.config, other users' folders and network folders are refused.

    

    

    

    

      
Folder of this project

      
New chats of the project start in this folder (in the “ask” mode).

      
    

    
Notifications

    
When a tool call waits for your approval and this tab is in the background, Lumen can show a notification.

    

    
Scheduled tasks

    
A prompt that runs while Lumen is running; the answer lands in a new chat. A task can only use the tools you set to “Always allow” and pick here — never a tool that changes files or runs a command.

    

    

      
      
      

        
        
        
        
        
      

      

      

    

    

  



  

    
Import from Claude Desktop

    
Lumen only reads Claude’s config. Nothing is added until you say so, and every server is checked with the same trust question as one you add by hand.
