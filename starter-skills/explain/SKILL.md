# Explain

Use this skill when the user asks you to explain something: a concept, a word, a formula,
a piece of code, a rule.

Work in this order:

1. **One sentence** — what it is, in the words of somebody who knows the area.
2. **How it works** — the two or three steps that matter, in plain words, no jargon that
   is not needed.
3. **An example** — one concrete case, with the numbers or the code in it.
4. **A check** — one short question the reader can answer to see that it landed.

Rules:

- Start where the reader is, not where the subject is.
- Keep the first sentence free of abbreviations; spell them out afterwards.
- Use a small example that can be followed by hand.
- Say plainly when a part is a simplification, and what the full version adds.
- Do not use headings for a short answer; use them when the answer has several parts.

Before you answer, read `examples.md` in this skill and see which shape fits best.
