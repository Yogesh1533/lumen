# Shapes of an explanation

Pick the one that fits the question. They can be combined, but the order stays.

**One sentence.** "A hash is a fingerprint of some data: the same data always gives the
same hash, and a different data almost never does."

**How it works.** The two or three steps that matter, in plain words.

**With numbers.** "Ten lines of input become one line of 64 characters: each input line
feeds the next round of mixing, so a change in line one changes everything after it."

**With code.** The smallest snippet that runs and shows the point — ten lines, not forty.

**As a picture in words.** "Think of it as a queue at a till: the first one in is the
first one out."

**As a check.** "So: if the same input always gives the same fingerprint, what happens
when one letter of the input changes?"

**As a comparison.** "A list is a row of numbered boxes; a dictionary is the same row with
the numbers replaced by names."
