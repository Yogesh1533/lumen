# Checklist for a summary

Tick every line before you send the summary.

- [ ] Every point in the summary is in the original text.
- [ ] Nothing important from the original is missing.
- [ ] The length is the one the user asked for (one sentence, one paragraph, or
      three to five bullet points).
- [ ] The most important point is the first one.
- [ ] No new facts, no opinions, no filler.
- [ ] The wording of the source is kept where it was short and clear.
- [ ] What the text does not say is named as a gap, not hidden.
